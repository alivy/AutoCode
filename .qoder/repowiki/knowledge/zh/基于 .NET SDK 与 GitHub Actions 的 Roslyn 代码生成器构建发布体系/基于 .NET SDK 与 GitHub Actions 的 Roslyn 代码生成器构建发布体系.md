## 构建系统与工具链

该项目采用标准的 .NET SDK 工程结构，以 `src/AutoCode.sln` 为解决方案入口，使用 MSBuild 进行编译、测试和打包。CI/CD 通过 GitHub Actions 在 `main` 分支推送和标签触发，运行在 `ubuntu-latest` 环境，固定使用 `.NET 8.0.x`。

## 核心构建流程

### 1. 解决方案与项目组织
- 解决方案文件：`src/AutoCode.sln`，包含约 20 个项目，涵盖 SourceGenerator、Analyzers、示例应用、测试等
- 所有 C# 项目均使用 SDK 风格（Sdk="Microsoft.NET.Sdk"），无自定义 MSBuild 脚本
- 多目标框架策略：
  - 运行时应用（APP、APP.WebAPI、DotTemplate.APP 等）：`net8.0`
  - SourceGenerator/Analyzer 库：`netstandard2.0` / `netstandard2.1`
  - 确保与 Roslyn 分析器的兼容性

### 2. CI/CD 流水线（GitHub Actions）
定义在 `.github/workflows/ci.yml`，包含三个核心阶段：

**build-and-test**（所有 push/pull_request）：
- `dotnet restore src/AutoCode.sln` → 恢复依赖
- `dotnet build --configuration Release` → 编译解决方案
- `dotnet test --configuration Release` → 执行单元测试

**pack**（仅 v* 标签触发）：
- 单独构建 `AutoCode.SourceGenerator.Extensions.csproj`，配置为 `Publish`
- 将生成的 `.nupkg` 上传到 Artifacts

**publish**（仅 v* 标签触发）：
- 下载上一步的 nupkg
- 遍历 `src/.nuget/*.nupkg` 并推送到 NuGet.org

### 3. NuGet 包构建机制
`AutoCode.SourceGenerator.Extensions.csproj` 是包的聚合入口，关键特性：
- `DevelopmentDependency=true`：标记为开发依赖，不传递到运行时
- `IncludeBuildOutput=false`：不包含默认输出，手动控制打包内容
- **PreBuild Target**（仅在 Publish 配置时）：自动 publish 所有子项目到 `NugetPackage/analyzers/dotnet/cs` 目录
- **PostBuild Target**（仅在 Publish 配置时）：执行 `dotnet pack` 输出到 `src/.nuget/`
- 包结构：
  - `analyzers/dotnet/cs/`：所有 Roslyn 分析器和生成器 DLL
  - `lib/netstandard2.1/`：运行时模型库
  - `tools/`：安装脚本（init.ps1, install.ps1, uninstall.ps1）

### 4. 版本管理策略
- 版本号直接写在 csproj 中（如 `<Version>1.2.0</Version>`）
- 通过 Git 标签 `v*` 触发发布流程
- 多个项目共享相同版本号（CLI、扩展包等均为 1.2.0）

### 5. 代码规范与质量
- `.editorconfig` 统一编码风格：CRLF 换行、4 空格缩进、PascalCase 命名
- 启用 Nullable 引用类型检查（`<Nullable>enable</Nullable>`）
- 禁用 RS1036 分析器警告（SourceGenerator 开发需要）
- 强制 CS8618 非空字段初始化警告

### 6. 本地开发工作流
- 使用 Visual Studio 2022（VS 17.8.34316.72）或 VS Code
- 支持 Debug/Release/Publish 三种配置
- 支持 Any CPU/x64/x86 平台组合
- 内置测试项目 `AutoCode.Tests` 验证各生成器功能

## 约束与约定
- 所有 SourceGenerator 必须实现 `IIncrementalGenerator` 接口
- Analyzers 遵循 Microsoft.CodeAnalysis.Analyzers 规范
- 包发布必须通过 Git 标签 `vX.Y.Z` 格式触发
- 禁止直接修改 `NugetPackage/` 目录，由 PreBuild 自动生成
- 所有公共 API 需生成 XML 文档（`<DocumentationFile>`）

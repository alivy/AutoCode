该仓库是一个基于 Roslyn IIncrementalGenerator 的 C# 编译时代码生成工具集，核心功能是通过属性约定自动生成接口、DTO、映射、依赖注入、验证与 Web API 控制器等后端代码。经全面检索，仓库中不存在任何前端相关代码（无 .css、.scss、.less、.sass、.styl、.tsx、.jsx、.vue、.html 文件），也未引入任何前端样式框架或 UI 库（如 Bootstrap、Material-UI、Ant Design、Tailwind CSS、Emotion、styled-components 等）。因此，本仓库不涉及前端样式（frontend_style）范畴。

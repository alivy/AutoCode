根级命令：`dotnet build src/AutoCode.sln` 构建全部项目；`dotnet test src/AutoCode.sln` 运行所有测试；`dotnet run --project src/AutoCode.Benchmarks -c Release -- --quick` 执行 AOP 性能基准；`dotnet tool install -g AM.AutoCode.Cli` 安装 CLI；`dotnet new install AM.AutoCode.Templates && dotnet new autocode-webapi -n MyProject` 使用模板创建项目；`./scripts/install-autocode.ps1 -ProjectPath ./MyApp -WithSamples` 一键安装。

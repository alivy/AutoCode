- 所有命令 ID 统一以 `autocode.` 前缀命名（如 `autocode.install`、`autocode.generate`），并在 commands、menus、commandPalette 三处保持一致引用。
- Snippets 采用 JSON 键名即显示名称、`prefix` 触发词、`body` 数组逐行模板、`description` 说明的标准结构，占位符使用 `${n:name}` 语法。
- 编辑器上下文菜单通过 `when: editorLangId == csharp` 限制仅在 C# 文件中可见，资源管理器菜单通过 `when: resourceExtname == .csproj` 限定作用域。
- 配置项统一放在 `contributes.configuration.properties` 下并以 `autocode.` 为命名空间前缀，每个属性包含 type、default、description 三字段。

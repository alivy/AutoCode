该模块是一个标准的 VS Code 扩展包，入口由 `package.json` 声明：主程序位于 `./out/extension.js`（TypeScript 编译产物），通过 `activationEvents: onLanguage:csharp` 在打开 C# 文件时激活。扩展通过 `contributes.commands` 注册 6 个命令（install/generate/preview/doctor/addIntercept/addEntity），并通过 `menus.editor/context`、`explorer/context`、`commandPalette` 将命令绑定到编辑器右键、资源管理器右键和命令面板；Snippets 通过 `contributes.snippets` 指向 `snippets/autocode.json`，为 C# 语言提供 12 个代码片段（AutoEntity/AutoIntercept/AutoController/AutoDTO/AutoValidator/AutoCrud/AutoTest 等）。配置项集中在 `contributes.configuration`，暴露 `showCodeLens` 与 `defaultInterceptors` 两个设置。依赖方向单一：扩展仅依赖 `@types/vscode` 类型定义，运行时逻辑由 TypeScript 源码编译到 `out/` 目录后由 VS Code 加载。

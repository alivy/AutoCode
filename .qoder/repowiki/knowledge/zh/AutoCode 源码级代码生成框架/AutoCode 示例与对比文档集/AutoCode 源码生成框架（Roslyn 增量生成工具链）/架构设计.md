根仓库通过 AutoCode.sln 将能力按职责分层并依赖单向聚合：
- 契约层（AutoCode.Model）集中定义所有 Attribute（AutoInterface/AutoEntity/AutoDTO/AutoController/AutoIntercept 等）、AutoCodeOptions 与 IInterceptHandler，被 Engine、Generators、Analyzers、Samples 共同引用。
- 引擎层（AutoCode.Engine）提供 GenerationPipeline（拓扑排序 + 优先级调度）、IGenerationPlugin 插件契约、ConventionEngine 约定推断、DiagnosticCollector 诊断收集以及 CodeWriter/ClassBuilder/MethodBuilder Fluent 构建器；Roslyn 入口 AutoCodeIncrementalGenerator 在此统一注册并驱动各插件。
- 插件实现层（AutoCode.Generators V1/V2）每个子目录对应一种生成能力（Interface/Dto/Mapper/Validation/WebApi/DI/Testing/Logging/Crud/Cascade/Intercept），均基于 Engine 的 GenerationPluginBase 实现并通过 autocode.json 配置启停。
- 横向支撑：AutoCode.Analyzers 提供 AC001~AC8xxx 诊断与 CodeFix；AutoCode.Cli 暴露命令行入口；AutoCode.Extensions.SourceGenerator 负责 NuGet 打包与 analyzers/tools 目录装配；AutoCode.DotTemplate.SourceGenerator 提供 XML/Liquid 模板支持。
- 应用与工具层：APP.WebAPI 演示运行时 AOP 拦截；samples/ 提供渐进式示例；templates/ 提供 dotnet new 模板；scripts/install-autocode.ps1 一键安装；tools/vscode-extension/ 提供 VS Code 集成。
V1 生成器保留在独立项目中保持向后兼容，V2 引擎通过 IncrementalGenerator 作为 Roslyn 入口统一调度所有插件，形成“特性 → 约定 → 插件管线 → 输出代码”的单向数据流。

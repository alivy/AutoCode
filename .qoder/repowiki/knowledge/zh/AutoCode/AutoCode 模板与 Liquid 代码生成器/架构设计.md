本模块由两层组成：顶层 `templates/autocode-webapi` 是标准的 `Microsoft.NET.Sdk.Web` 项目，通过 `.template.config/template.json` 注册为 `dotnet new` 可安装模板（identity: `AM.AutoCode.Templates.WebApi`），入口 `Program.cs` 使用 Minimal API 风格构建并依赖 `AM.AutoCode` NuGet 包在编译时执行源生成；根目录下的 `AuditService.liquid` 和 `Repository.liquid` 是独立的 DotLiquid 模板文件，分别用于生成审计日志包装器和内存仓储 CRUD 实现，它们通过 `{{ Namespace }}`、`{{ ClassName }}`、`{{ Methods }}`、`{{ Properties }}` 等变量从 autocode.json 配置中注入上下文。两者共同服务于同一目标：用户通过 autocode.json + Liquid 模板声明代码生成规则，无需修改框架源码即可新增生成器，体现「以实体为中心」的声明式生成架构。

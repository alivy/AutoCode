- 所有用户交互输出通过 Write-Step/Write-OK/Write-Warn/Write-Err 四个封装函数统一前缀标签和颜色，避免直接使用 Write-Host
- 脚本采用分步推进结构，每个主要阶段用 Write-Step 标注步骤名并以 try/catch 包裹可能失败的命令
- 配置文件生成使用 PowerShell hashtable 定义结构后通过 ConvertTo-Json 序列化为 UTF8 编码的 JSON 文件
- 可选功能通过 [switch] 参数控制，并在执行前用 if ($WithSamples) / if (-not $SkipDoctor) 条件分支包裹对应逻辑块

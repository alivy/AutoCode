- 所有生成器均实现 IIncrementalGenerator 接口，通过 context.AddSource 输出代码而非写磁盘文件
- 插件统一继承 GenerationPluginBase，通过 Name/Priority/AttributeFullName/Generate 四个核心成员声明行为
- 特性标记集中在 AutoCode.Model 项目，命名遵循 AutoXxxAttribute 模式（如 AutoInterfaceAttribute、AutoEntityAttribute）
- JSON 配置采用 autocode.json 文件，plugins 节下每个插件以 enabled 开关控制
- MSBuild 属性以 AutoCode_ 前缀覆盖默认行为（如 AutoCode_InterfacePrefix、AutoCode_MapMethodName）
- 分析器诊断 ID 遵循 AC + 数字 格式，CodeFix 通过 VisualStudio.CodeFixProvider 提供 Ctrl+. 修复

- 实体类通过组合 `[AutoEntity]`、`[AutoInterface]`、`[AutoIntercept]` 等特性声明式驱动代码生成，而非手写实现类
- 数据验证统一使用 System.ComponentModel.DataAnnotations 特性（如 `[Required]`、`[MaxLength]`、`[Range]`）标注字段
- Program.cs 采用 Minimal API 风格，仅保留 DI、中间件配置和路由映射，业务逻辑完全交由生成器产出
- 模板参数通过 template.json 中的 symbols 节点以布尔类型定义，默认值均为 true 以启用完整功能

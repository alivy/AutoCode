该模块是一个标准的 .NET 项目模板（`Microsoft.NET.Sdk.Web`），通过 `.template.config/template.json` 注册为 `dotnet new` 可安装的模板，标识为 `AM.AutoCode.Templates.WebApi`，短名为 `autocode-webapi`。模板提供三个布尔参数 `enableCrud`、`enableIntercept`、`enableValidation` 控制生成行为。入口 `Program.cs` 使用 Minimal API 风格构建 Web 应用，依赖 `AM.AutoCode` NuGet 包在编译时执行源生成；示例实体 `Entities/Product.cs` 通过 `[AutoEntity]`、`[AutoInterface]`、`[AutoIntercept]` 等特性声明式驱动全链路代码生成，体现“以实体为中心”的代码生成架构。依赖方向单向：模板 → AM.AutoCode 源生成器 → 生成的代码。

根仓库以 AutoCode.sln 为统一解决方案入口，将代码按职责划分为三层：
- 核心引擎层：AutoCode.Engine 提供 GenerationPipeline（依赖拓扑排序 + 优先级调度）、IGenerationPlugin 契约、CodeWriter/ClassBuilder/MethodBuilder Fluent 构建器、ConventionEngine 约定推断、DiagnosticCollector 诊断收集；AutoCode.Model 集中定义所有特性标记（AutoInterface/AutoEntity/AutoDTO/AutoController/AutoIntercept 等），是全部插件共享的类型契约。
- 插件实现层：AutoCode.Plugins.* 每个子项目对应一个生成能力（Interface/Mapper/Dto/Validation/WebApi/DependencyInjection/Testing/Logging/Crud/Cascade/Intercept），均继承自 Engine 中的 GenerationPluginBase，通过 autocode.json 配置启停与行为。
- 应用与工具层：APP / APP.WebAPI / Samples 演示用法；AutoCode.Analyzers 提供 AC001~AC8xxx 诊断规则与 CodeFix；AutoCode.Cli 提供命令行工具；AutoCode.Extensions.SourceGenerator 负责 NuGet 打包；templates/ 提供 dotnet new 模板；scripts/ 提供一键安装 PowerShell 脚本；tools/vscode-extension/ 提供 VS Code 扩展。
V1 生成器（AutoCodeGenerator/AutoCode.Map/AutoCode.Dto 等）保留在独立项目中保持向后兼容，V2 引擎通过 AutoCode.IncrementalGenerator 作为 Roslyn 入口统一调度所有插件。

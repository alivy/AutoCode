该仓库是一个基于 Roslyn 的 C# 编译时代码生成框架，核心功能是通过特性标记和插件化管线自动生成接口、DTO、映射器、Web API、依赖注入、验证、日志、测试等后端代码。仓库中不存在任何前端样式相关代码（CSS、SCSS、Tailwind、设计令牌、组件库或 UI 主题文件），也不包含 HTML、JavaScript、TypeScript 前端页面或 Vue/React/Svelte 等前端框架代码。唯一的 VS Code 扩展位于 `tools/vscode-extension/`，仅包含 `package.json` 和 snippets 配置，用于提供命令、菜单和代码片段，不包含任何前端样式定义。因此，本仓库不涉及前端样式系统的范畴。

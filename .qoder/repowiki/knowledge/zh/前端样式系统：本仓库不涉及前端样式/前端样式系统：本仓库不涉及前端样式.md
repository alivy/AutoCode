经全面检索，该仓库是一个纯 C#/.NET 编译时代码生成框架（基于 Roslyn IIncrementalGenerator），不包含任何前端代码。仓库中不存在 .css、.scss、.less、.sass、.styl、.html、.js、.ts、.jsx、.tsx 等前端样式或 UI 文件，也没有 package.json、tailwind.config、vite.config、webpack.config 等前端构建配置。所有项目均为 .csproj 的 .NET 工程，用于在编译期自动生成接口、DTO、映射、依赖注入、验证与 Web API 控制器等后端样板代码。因此，frontend_style 类别不适用于此仓库。

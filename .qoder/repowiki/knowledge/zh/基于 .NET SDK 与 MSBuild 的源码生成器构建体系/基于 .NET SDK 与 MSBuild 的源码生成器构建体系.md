本仓库采用标准的 .NET SDK 项目格式（Sdk="Microsoft.NET.Sdk"），通过 Visual Studio Solution（AutoCode.sln）统一管理多个 C# 项目，核心构建系统由 MSBuild + dotnet CLI 驱动，无外部 Makefile 或 Docker 配置。

**构建工具与框架**
- 使用 .NET 8.0 作为主要目标框架（应用与测试项目），源码生成器类库统一 targeting netstandard2.0/netstandard2.1 以兼容多版本宿主
- 所有项目均启用 `<Nullable>enable</Nullable>` 与 `<LangVersion>12.0</LangVersion>`，测试项目使用 xUnit + Microsoft.NET.Test.Sdk
- 解决方案文件 AutoCode.sln 声明了 Debug/Release/Publish 三种配置以及 Any CPU/x64/x86 平台组合

**源码生成器构建模式**
- 三个 SourceGenerator 项目（AutoCode.SourceGenerator、AutoCode.DotTemplate.SourceGenerator、AutoCode.Map）均引用 Microsoft.CodeAnalysis.CSharp 和 Microsoft.CodeAnalysis.Analyzers，并设置 `EnforceExtendedAnalyzerRules=true` 遵循 Roslyn 分析器规则
- 生成器项目通过 `<ProjectCapability Include="SourceGeneration" />` 标记为源码生成器
- 应用项目通过 `OutputItemType="Analyzer" ReferenceOutputAssembly="false"` 的方式引用本地生成器项目，实现开发时增量编译

**NuGet 包发布流程**
- AutoCode.Extensions.SourceGenerator.csproj 是统一的 NuGet 打包入口，定义 PackageId="AM.AutoCode"、Version="1.2.0"、DevelopmentDependency=true
- Publish 配置下通过 PreBuild Target 调用 `dotnet publish` 将各生成器与模型项目输出到 NugetPackage/analyzers/dotnet/cs 目录
- PostBuild Target 执行 `dotnet pack` 生成 .nupkg 到 `.nuget/` 目录
- 包结构包含 analyzers/dotnet/cs（生成器 DLL）、tools/install.ps1（自动注入 Analyzer 引用）、lib/netstandard2.1（运行时依赖）
- install.ps1 脚本在安装时自动扫描 analyzers 目录并将 DLL 添加到项目的 AnalyzerReferences

**测试与验证**
- AutoCode.Tests 项目引用所有生成器与 Model 项目，使用 xUnit 框架进行单元测试
- coverlet.collector 用于代码覆盖率收集
- 测试项目设置 `<IsPackable>false</IsPackable>` 避免被打包

**约束与约定**
- 生成器项目必须 targeting netstandard2.0+，确保可被任意 .NET 宿主加载
- 所有生成器项目禁用 `<IncludeBuildOutput>true</IncludeBuildOutput>`，仅输出 analyzer DLL
- 解决方案中通过 NestedProjects 将 APP.Map、AutoCode.MapDebug、Auto.MapModels 归入 AutoCodeMap 分组
- 文档 XML 通过 `<DocumentationFile>bin\$(Configuration)\$(TargetFramework)\$(AssemblyName).xml</DocumentationFile>` 自动生成

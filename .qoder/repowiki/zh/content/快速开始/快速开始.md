## 简介
本快速开始指南帮助您在15分钟内完成 AutoCode 的环境准备、安装配置与第一个示例运行。AutoCode 通过编译时代码生成技术，根据属性标记自动生成接口、映射代码、验证逻辑等，大幅减少样板代码，提升开发效率。

**核心特性：**
- 零运行时开销：所有代码在编译时生成
- 全链路生成：一个特性触发完整业务链路代码生成
- 高度可配置：通过 JSON 配置文件统一管理行为
- 无缝集成：与现有 .NET 生态完美兼容

## 快速安装
AutoCode 提供了一键安装脚本，可在5分钟内完成项目集成：

### 方法一：使用一键安装脚本（推荐）
```powershell
# 在项目根目录执行
.\scripts\install-autocode.ps1

# 带示例代码安装
.\scripts\install-autocode.ps1 -WithSamples

# 指定项目路径
.\scripts\install-autocode.ps1 -ProjectPath ./MyApp
```

### 方法二：手动安装
```bash
# 添加 NuGet 包
dotnet add package AM.AutoCode --prerelease

# 或引用项目（开发阶段）
dotnet add reference ..\AutoCode.Model\AutoCode.Model.csproj
```

### 安装脚本功能
- 自动检测项目文件并安装依赖
- 初始化 autocode.json 配置文件
- 可选创建示例实体代码
- 运行环境诊断检查

## 项目配置
安装完成后，项目根目录会生成 `autocode.json` 配置文件，这是 AutoCode 的核心配置中心：

### 基础配置结构
```json
{
  "conventions": {
    "servicePattern": "*Service",
    "repositoryPattern": "*Repository", 
    "dtoSuffix": "Dto",
    "autoDetectServices": true,
    "autoDetectDtos": true
  },
  "mapper": {
    "methodName": "MapTo",
    "nullHandling": "Skip",
    "collectionMapping": "DeepCopy"
  },
  "plugins": {
    "interface": { "enabled": true },
    "mapper": { "enabled": true },
    "dto": { "enabled": true },
    "validation": { "enabled": true },
    "webapi": { "enabled": true }
  }
}
```

### 主要配置模块
- **conventions**：命名约定和自动检测规则
- **mapper**：对象映射配置
- **dto**：DTO 生成选项
- **webapi**：Web API 生成配置  
- **validation**：验证规则配置
- **dependencyInjection**：依赖注入配置
- **cascade**：级联生成控制
- **logging**：日志配置
- **intercept**：拦截器配置
- **plugins**：插件开关管理
- **customGenerators**：自定义生成器定义

## 第一个示例
让我们创建一个完整的 CRUD 应用示例：

### 步骤1：创建实体类
```csharp
using AutoCode.Model;
using System.ComponentModel.DataAnnotations;

namespace MyApp.Entities
{
    [AutoEntity]  // 一行特性，生成完整业务链路
    public class Product
    {
        public int Id { get; set; }

        [Required]
        [MaxLength(200)]
        public string Name { get; set; } = "";

        [Range(0.01, 99999)]
        public decimal Price { get; set; }

        public string? Description { get; set; }
        
        public DateTime CreatedAt { get; set; } = DateTime.UtcNow;
    }
}
```

### 步骤2：编译并查看生成代码
```bash
# 编译项目
dotnet build

# 查看生成的代码文件
# 位置：obj/Debug/net8.0/generated/
```

### 步骤3：生成的代码文件
编译后会自动生成以下文件：
- `ProductDto.g.cs` - DTO 和数据传输对象
- `ProductMapper.g.cs` - 对象映射器
- `ProductValidator.g.cs` - 数据验证器
- `IProductRepository.g.cs` + `ProductRepository.g.cs` - 仓储层
- `IProductService.g.cs` + `ProductService.g.cs` - 服务层
- `ProductsController.g.cs` - RESTful API 控制器
- `ProductDI.g.cs` - 依赖注入注册

### 步骤4：使用生成的代码
```csharp
// 直接使用生成的服务
var service = new ProductService();
var product = await service.GetByIdAsync(1);
```

## 故障排除
### 常见问题及解决方案

#### 1. 生成器未生效
**问题**：编译后没有生成预期代码
**解决方案**：
- 确认已安装正确的 NuGet 包
- 检查 autocode.json 配置是否正确
- 清理并重新构建项目：`dotnet clean && dotnet build`

#### 2. 配置文件错误
**问题**：autocode.json 格式错误或包含无效配置
**解决方案**：
- 使用 JSON 验证工具检查配置格式
- 参考默认配置模板
- 逐步启用插件进行排查

#### 3. 权限问题
**问题**：PowerShell 脚本执行被阻止
**解决方案**：
```powershell
# 设置执行策略
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
```

#### 4. 依赖冲突
**问题**：与其他库的依赖版本冲突
**解决方案**：
- 检查项目中的依赖版本兼容性
- 使用 NuGet 包管理器控制台更新依赖
- 考虑使用项目引用代替 NuGet 包

#### 5. 生成代码位置
**问题**：找不到生成的代码文件
**解决方案**：
- 查看 `obj/Debug/net8.0/generated/` 目录
- 启用编译器输出：`<EmitCompilerGeneratedFiles>true</EmitCompilerGeneratedFiles>`

## 进阶使用

### 使用拦截器增强功能
```csharp
[AutoIntercept(InterceptType.Log | InterceptType.Cache | InterceptType.Metrics)]
public class OrderService : IOrderService
{
    public async Task<Order> GetOrderAsync(int id)
    {
        return await _db.Orders.FindAsync(id);
    }
}
```

### 自定义生成器
通过 autocode.json 中的 customGenerators 配置，可以定义自己的代码生成逻辑：

```json
{
  "customGenerators": [
    {
      "name": "auditService",
      "title": "添加审计日志服务",
      "trigger": {
        "classPattern": "*Service",
        "attributeName": "AutoAudit"
      },
      "output": {
        "template": "templates/AuditService.liquid",
        "fileName": "{ClassName}Audit.g.cs"
      }
    }
  ]
}
```

### 模板引擎
AutoCode 支持 Liquid 模板语法，可以自定义生成代码的格式和内容。

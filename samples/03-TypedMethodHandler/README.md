# 03 - 强类型方法拦截器（IMethodHandler）

> 展示：生成器自动产出 Args record，用户 Handler 直接拿到类型化参数和返回值。

## 核心流程

```
你写的方法签名:
  Task<bool> ChargeAsync(int orderId, decimal amount)

生成器自动产出:
  public record ChargeAsyncArgs(int OrderId, decimal Amount);  ← 自动生成，无需手写

你的 Handler:
  class ChargeAuditHandler : MethodHandlerBase<ChargeAsyncArgs, bool>
  {
      OnBefore(ChargeAsyncArgs args, MethodContext ctx)
      {
          args.OrderId   ← 强类型，有 IntelliSense
          args.Amount    ← 编译时类型安全
      }
      OnAfter(ChargeAsyncArgs args, bool result, MethodContext ctx)
      {
          result         ← 强类型 bool，直接做数据处理
          ctx.Elapsed    ← 耗时
      }
  }
```

## 完整示例

### 1. 定义 Service（方法级标记）

```csharp
using AutoCode.Model;

[AutoInterface]
public class PaymentService : IPaymentService, IScoped
{
    // 方法级：Log + Retry + 强类型审计 Handler
    [AutoIntercept(InterceptType.Log | InterceptType.Retry, MaxRetryCount = 3)]
    [CustomIntercept(typeof(ChargeAuditHandler))]
    public async Task<bool> ChargeAsync(int orderId, decimal amount)
    {
        await Task.Delay(200);
        if (new Random().NextDouble() < 0.2)
            throw new TimeoutException("支付网关超时");
        return true;
    }

    // 方法级：仅强类型数据收集
    [CustomIntercept(typeof(RefundCollectorHandler))]
    [AutoIntercept(InterceptType.Log)]
    public async Task RefundAsync(int orderId, string reason)
    {
        await Task.Delay(100);
    }

    // 无标记 → 不拦截
    public bool HealthCheck() => true;
}
```

### 2. 定义 Handler（强类型，生成器自动提供 Args）

```csharp
// ChargeAsyncArgs 由生成器自动产出，无需手写！
// public record ChargeAsyncArgs(int OrderId, decimal Amount);  ← 自动生成

public class ChargeAuditHandler : MethodHandlerBase<ChargeAsyncArgs, bool>
{
    public override void OnBefore(ChargeAsyncArgs args, MethodContext ctx)
    {
        Console.WriteLine($"[审计] 扣款: 订单={args.OrderId}, 金额={args.Amount:C}");

        // 短路：金额超限直接拒绝
        if (args.Amount > 100000)
        {
            ctx.ShortCircuit = true;
            ctx.Result = false;
        }
    }

    public override void OnAfter(ChargeAsyncArgs args, bool result, MethodContext ctx)
    {
        // result 是强类型 bool，直接处理
        if (result)
            Console.WriteLine($"[审计] 成功: 订单={args.OrderId}, 耗时={ctx.Elapsed.TotalMilliseconds}ms");
    }

    public override void OnException(ChargeAsyncArgs args, Exception ex, MethodContext ctx)
    {
        Console.WriteLine($"[告警] 订单{args.OrderId}扣款异常: {ex.Message}");
    }
}

// RefundAsyncArgs 也由生成器自动产出
// public record RefundAsyncArgs(int OrderId, string Reason);  ← 自动生成

public class RefundCollectorHandler : MethodHandlerBase<RefundAsyncArgs, object>
{
    public override void OnAfter(RefundAsyncArgs args, object result, MethodContext ctx)
    {
        Console.WriteLine($"[对账] 退款: 订单={args.OrderId}, 原因={args.Reason}");
    }
}
```

### 3. 生成器自动产出的代码

编译后在 `obj/Debug/net8.0/generated/AutoCode.Intercept/` 下：

**PaymentService.Args.g.cs**（自动生成）:
```csharp
// <auto-generated/>
public record ChargeAsyncArgs(int OrderId, decimal Amount);
public record RefundAsyncArgs(int OrderId, string Reason);
public record GetPaymentStatusArgs(int OrderId);
public record HealthCheckArgs;
```

**InterceptedPaymentService.g.cs**（自动生成）:
```csharp
public sealed class InterceptedPaymentService : IPaymentService
{
    private readonly IPaymentService _inner;
    private readonly ILogger<InterceptedPaymentService> _logger;
    private readonly ChargeAuditHandler _chargeAuditHandler;
    private readonly RefundCollectorHandler _refundCollectorHandler;

    public async Task<bool> ChargeAsync(int orderId, decimal amount)
    {
        // 构造强类型 Args
        var __args = new ChargeAsyncArgs(orderId, amount);
        var __mctx = new MethodContext { ClassName = "PaymentService", MethodName = "ChargeAsync" };

        // 调用 Handler.OnBefore（强类型）
        _chargeAuditHandler.OnBefore(__args, __mctx);
        if (__mctx.ShortCircuit)
            return (bool)__mctx.Result!;

        _logger.LogInformation("ChargeAsync 开始, orderId={orderId}, amount={amount}", orderId, amount);
        var __sw = Stopwatch.StartNew();

        for (int __attempt = 1; ; __attempt++)
        {
            try
            {
                var __result = await _inner.ChargeAsync(orderId, amount);
                _logger.LogInformation("ChargeAsync 完成, 耗时 {Elapsed}ms", __sw.ElapsedMilliseconds);
                __mctx.Elapsed = __sw.Elapsed;
                _chargeAuditHandler.OnAfter(__args, __result, __mctx);  // ← 强类型 result
                return __result;
            }
            catch (Exception __ex) when (__attempt < 3)
            {
                __mctx.Elapsed = __sw.Elapsed;
                __mctx.AttemptNumber = __attempt;
                _chargeAuditHandler.OnException(__args, __ex, __mctx);
                await Task.Delay(__attempt * 500);
            }
        }
    }

    // HealthCheck → 直接透传
    public bool HealthCheck() => _inner.HealthCheck();
}
```

## 对比：旧方式 vs 新方式

| 维度 | 旧（InterceptContext） | 新（IMethodHandler<TArgs, TResult>） |
|------|----------------------|--------------------------------------|
| 参数获取 | `(int)ctx.Arguments["orderId"]` 手动强转 | `args.OrderId` 直接用 |
| 返回值 | `(bool)result!` 可能 NRE | `bool result` 编译时安全 |
| IntelliSense | ❌ 字典 key 靠记忆 | ✅ 完整属性提示 |
| 重构安全 | ❌ 改参数名不报错 | ✅ 编译期发现 |
| Args 定义 | 手动写 record | **生成器自动产出** |

## 两层拦截器选择指南

| 场景 | 用哪个 | 原因 |
|------|--------|------|
| 日志/指标/并发计数 | `IInterceptHandler` | 不关心具体方法签名 |
| 数据收集/业务审计 | `IMethodHandler<TArgs, TResult>` | 需要知道参数和结果 |
| 权限校验/限流 | `IInterceptHandler` | 通用横切 |
| 结果加工/脱敏 | `IMethodHandler<TArgs, TResult>` | 需要操作返回值 |
| 财务对账/告警 | `IMethodHandler<TArgs, TResult>` | 需要具体业务数据 |
